# الوكلاء

## نظرة عامة

يحتوي المشروع على **22 وكيل** متخصص، كل وكيل مصمم لمجال محدد من هندسة البرمجيات.

## قائمة الوكلاء

| الوكيل | التخصص | للقراءة |
|--------|--------|---------|
| **frontend** | واجهات المستخدم وReact وNext.js | [التفاصيل](/ar/agents/) |
| **backend** | APIs والمنطق الخلفي | [التفاصيل](/ar/agents/) |
| **database** | قواعد البيانات والمخططات | [التفاصيل](/ar/agents/) |
| **security** | الأمان والمصادقة | [التفاصيل](/ar/agents/) |
| **performance** | تحسين الأداء | [التفاصيل](/ar/agents/) |
| **architect** | التصميم المعماري | [التفاصيل](/ar/agents/) |
| **reviewer** | مراجعة الكود | [التفاصيل](/ar/agents/) |
| **tester** | الاختبارات | [التفاصيل](/ar/agents/) |
| **devops** | النشر والبنية التحتية | [التفاصيل](/ar/agents/) |
| **i18n** | التدويل وRTL | [التفاصيل](/ar/agents/) |
| **ai-engineer** | هندسة الذكاء الاصطناعي | [التفاصيل](/ar/agents/) |
| **designer** | أنظمة التصميم | [التفاصيل](/ar/agents/) |

## كيف تعمل الوكلاء

1. المستخدم يستدعي الوكيل عبر `@agent`
2. الوكيل يُحمّل المهارات المناسبة لمهمته
3. الوكيل يبحث في المعرفة عن السياق
4. الوكيل يقدم الحل أو الاقتراح
