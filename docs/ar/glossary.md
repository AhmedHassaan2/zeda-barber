# المعجم

## مصطلحات أساسية

| المصطلح | التعريف |
|---------|---------|
| **وكيل (Agent)** | مساعد ذكاء ااصطناعي متخصص في مجال محدد من هندسة البرمجيات |
| **مهارة (Skill)** | وحدة معرفية قابلة للتحميل عند الطلب |
| **أمر (Command)** | أمر شاشة موجه يُنفّذ سير عمل محدد |
| **دليل إرشاد (Playbook)** | خطوات عملية لسير عمل معقد |
| **مولّد (Generator)** | أداة لإنشاء مكونات جديدة تلقائيًا |
| **وثيقة معرفية (Knowledge Doc)** | مرجع تخصصي لمجال محدد |
| **مساحة العمل (Workspace)** | المجلد الرئيسي الذي تحتوي على جميع المكونات |
| **الطبقة الشخصية (Personal Layer)** | تفضيلات المستخدم الخاصة |
| **الطبقة المهنية (Professional Layer)** | معايير الهندسة الشاملة |
| **الطبقة المجالية (Domain Layer)** | معرفة التخصص |

## مصطلحات تقنية

| المصطلح | التعريف |
|---------|---------|
| **ADR** | قرار هندسي (Architecture Decision Record) |
| **OWASP** | مشروع أمان تطبيقات الويب المفتوح |
| **RTL** | من اليمين إلى اليسار (Right-to-Left) |
| **A11y** | إمكانية الوصول (Accessibility) |
| **RAG** | توليد المعرفة المعززة (Retrieval-Augmented Generation) |
| **MCP** | بروتوكول سياق النموذج (Model Context Protocol) |
