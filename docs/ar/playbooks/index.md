# كتب الإرشاد

## نظرة عامة

يحتوي المشروع على **16 دليل إرشاد** يغطي ساعر العمل الهندسية الأكثر شيوعًا.

## الدليلات المتاحة

| الدليل | الوصف |
|--------|-------|
| **feature-development** | تطوير ميزة جديدة من الصفر |
| **frontend-feature** | بناء مكون واجهة مستخدم |
| **backend-feature** | بناء نقطة نهاية خلفية |
| **api-development** | تصميم وبناء API |
| **bug-investigation** | التحقيق في الأخطاء |
| **code-review** | مراجعة الكود بشكل منهجي |
| **security-review** | مراجعة أمنية شاملة |
| **performance-optimization** | تحسين الأداء |
| **database-migration** | ترحيل قواعد البيانات |
| **deployment** | نشر التغييرات |
| **production-release** | إصدار إنتاجي |
| **new-project** | بدء مشروع جديد |
| **documentation** | كتابة التوثيق |
| **refactoring** | إعادة هيكلة الكود |
| **workspace-maintenance** | صيانة مساحة العمل |

## كيفية استخدام الدليلات

```bash
# استدعاء دليل محدد
@playbook: feature-development

# أو عبر الأمر
/new-project
```
