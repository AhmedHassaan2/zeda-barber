# الدليل السريع

## نظرة عامة سريعة

مساحة عمل Ahmed Enterprise AI Workspace هي منصة هندسة ذكاء اصطناعي مؤسسية متكاملة توفر لك:

- **22 وكيل** متخصص في مجالات هندسة البرمجيات المختلفة
- **81 مهارة** قابلة للتحميل حسب الطلب
- **22 أمر** جاهز لأتمتة سير العمل اليومي
- **16 دليل إرشاد** لـ complex workflows

## الخطوة 1: اختيار الوكيل المناسب

كل وكيل متخصص في مجال محدد. اختر الوكيل المناسب لمهمتك:

| المهمة | الوكيل المناسب | الأمر |
|--------|---------------|-------|
| بناء واجهة مستخدم | `frontend` | `@frontend` |
| إنشاء API | `backend` | `@backend` |
| مراجعة الكود | `reviewer` | `/review` |
| فحص الأمان | `security` | `/security-scan` |
| تحسين الأداء | `performance` | `/performance-check` |

## الخطوة 2: استخدام الأوامر

الأوامر المتاحة عبر `/` في واجهة OpenCode:

```bash
# مراجعة شاملة للكود
/review

# فحص أمني
/security-scan

# فحص الأداء
/performance-check

# فحص التوافقيات
/a11y-audit
```

## الخطوة 3: تحميل المهارات

المهارات تُحمّل تلقائيًا عند تطابق المهام. يمكنك أيضًا طلبها يدويًا:

```bash
# تحميل مهارة محددة
@skill: react-patterns
@skill: nextjs-app-router
```

## الخطوة 4: استخدام كتب الإرشاد

كتب الإرشاد توفر خطوات عملية لساعر العمل المعقدة:

```bash
# البدء في مشروع جديد
/new-project

# تطوير ميزة جديدة
@playbook: feature-development

# مراجعة أمنية
@playbook: security-review
```

## مثال عملي: بناء صفحة جديدة

```bash
# 1. إنشاء الصفحة
/new-page

# 2. إضافة مكون
/new-component

# 3. مراجعة الكود
/review

# 4. فحص التوافقيات
/a11y-audit
```

::: tip
ابدأ بقراءة [الهيكلة العامة](/ar/architecture) لفهم كيف تعمل مساحة العمل معًا.
:::
