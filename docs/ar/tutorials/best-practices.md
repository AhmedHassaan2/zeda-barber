# أفضل الممارسات

## 1. اختر الوكيل المناسب

- `@frontend` لواجهات المستخدم
- `@backend` للخلفيات والـ APIs
- `@security` للمراجعة الأمنية
- `@performance` لتحسين الأداء

## 2. استخدم الأوامر بدلاً من الوصف اليدوي

| بدلًا من | استخدم |
|---------|--------|
| "راجع هذا الكود" | `/review` |
| "افحص الأمان" | `/security-scan` |
| "حسّن الأداء" | `/performance-check` |

## 3. حمّل المهارات عند الحاجة

لا تحمل كل المهارات دفعة واحدة. احمّلها حسب الحاجة:

```
@skill: react-patterns     # عند العمل مع React
@skill: supabase-patterns  # عند العمل مع Supabase
```

## 4. استخدم كتب الإرشاد للمهام المعقدة

```
@playbook: feature-development   # لميزة جديدة
@playbook: security-review       # لمراجعة أمنية
```

## 5. حافظ على نظافة مساحة العمل

```
/workspace-validate    # التحقق من الصحة
/workspace-audit       # تدقيق شامل
/self-improve          # تحسين تلقائي
```

## 6. وثّق قراراتك

استخدم قرارات ADR لتوثيق القرارات المعمارية المهمة.

## 7. لا تهمل الأمان

- لا تحفظ الأسرار في الكود
- استخدم متغيرات البيئة
- راجع الأمان بانتظام

::: warning
لا تقم أبدًا بحفظ كلمات المرور أو مفاتيح API في مستودع Git.
:::
