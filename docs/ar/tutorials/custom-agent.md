# إنشاء وكيل مخصص

## النتيجة المتوقعة
ستتمكن من إنشاء وكيل مخصص لمتطلبات مشروعك.

## الخطوة 1: فهم هيكل الوكيل

كل وكيل هو ملف Markdown واحد:

```markdown
---
title: وصف مختصر
description: وصف تفصيلي للوكيل
---

أنت وكيل متخصص في [المجال].

## المسؤوليات
- [المسؤولية 1]
- [المسؤولية 2]

## الأنماط
- [النمط 1]
- [النمط 2]
```

## الخطوة 2: إنشاء ملف الوكيل

أنشئ ملف في `agents/my-custom-agent.md`:

```markdown
---
title: وكيل اختبار المكونات
description: متخصص في اختبار المكونات.React
---

أنت وكيل متخصص في اختبار مكونات React.

## المسؤوليات
- كتابة اختبارات وحدة باستخدام Vitest
- كتابة اختبارات تكامل باستخدام Playwright
- فحص التغطية وتحسينها

## الأنماط
- استخدم `describe` و`it` و`expect`
- افصل Arrange-Act-Assert
- اختبر الحالات الحدودية
```

## الخطوة 3: اختبار الوكيل

```
@custom-agent اختبر مكون الزر
```

## الخطوة 4: التحسين

- أضف مهارات محددة
- حسّن المسؤوليات
- أضف أمثلة

::: tip
استخدم أمر `/create-agent` لإنشاء وكيل من قالب.
:::
