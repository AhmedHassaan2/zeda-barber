# نظرة عامة على مساحة العمل

## المكونات الرئيسية

| المكون | العدد | الوصف |
|--------|-------|-------|
| الوكلاء | 22 | مساعدات ذكاء اصطناعي متخصصة |
| المهارات | 81 | وحدات معرفية قابلة للتحميل |
| الأوامر | 22 | أوامر جاهزة لأتمتة سير العمل |
| كتب الإرشاد | 16 | خطوات إرشادية لسير العمل المعقد |
| المولّدات | 6 | أدوات إنشاء تلقائي |

## الهيكل المجلدي

```
~/.config/opencode/
├── agents/           # 22 وكيل
├── skills/           # 81 مهارة
├── commands/         # 22 أمر
├── playbooks/        # 16 دليل إرشاد
├── generators/       # 6 مولّدات
├── knowledge/        # 35 وثيقة معرفية
├── examples/         # 36 مثال
├── templates/        # قوالب
├── workspace-memory/ # ذاكرة مساحة العمل
├── metrics/          # مقاييس الأداء
└── AGENTS.md         # القواعد العامة
```

## كيف يعمل معًا

1. **الوكيل** يستقبل المهمة من المستخدم
2. **المهارات** تُحمّل تلقائيًا حسب تخصص المهمة
3. **المعرفة** توفر السياق والتاريخ
4. **الأوامر** تُنفّذ سير العمل
5. **كتب الإرشاد** توجه الخطوات
