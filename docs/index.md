## Architecture Overview

The workspace is built on an **8-Layer Architecture** designed for enterprise-grade AI engineering:

| Layer | Scope | Components |
|-------|-------|------------|
| **Future** | Experimental | Plugin system, experimental features |
| **Automation** | Workflows | Commands, templates, generators |
| **Knowledge** | Learning | Memory, decisions, lessons learned |
| **Security** | Protection | Auth, secrets, compliance, audit |
| **Quality** | Review | Testing, review, accessibility, performance |
| **Domain** | Expertise | Skills, agent specializations |
| **Professional** | Standards | Universal engineering standards |
| **Personal** | Preferences | Ahmed's preferences and style |

## Quick Start

```bash
# Clone the workspace
git clone https://github.com/AhmedHassaan2/Ahmed-Enterprise-AI-Workspace.git

# Copy to OpenCode config
cp -r Ahmed-Enterprise-AI-Workspace/* ~/.config/opencode/

# Verify installation
opencode --version

# Run health check
/health-check
```

## Engineering Philosophy

This workspace follows a strict set of engineering principles:

- **TypeScript first** — strict mode, no `any`, explicit types
- **Next.js App Router** as the default React framework
- **Tailwind CSS** for all styling
- **Supabase** as the default backend
- **Vercel** as the default deployment target
- **Bilingual Arabic/English** with RTL-first design
- **Security by default** — never hardcode secrets, always validate input
- **Test what matters** — E2E for critical paths, unit for complex logic
- **Document decisions** — ADRs for architecture, comments for non-obvious logic
