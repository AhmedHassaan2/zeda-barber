# Workspace Metrics History

## Format

Each entry follows this structure:

```
YYYY-MM-DD | metric | value | change | notes
```

| Field | Description |
|-------|-------------|
| Date | Entry date |
| Metric | What was measured (e.g., `validation-score`, `agent-usage`, `security-score`) |
| Value | Numeric score or count |
| Change | Delta from previous entry (`+N`, `-N`, `0`, or `first`) |
| Notes | Context for the change |
